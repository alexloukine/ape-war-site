# Patch Notes

## v0.3.0 - February 2026

### New Features
- Added patch notes viewer accessible from the main menu
- Google Sign-In authentication for account persistence
- New cosmetics system with unlockable items

### Gameplay
- Reworked respawn system for faster re-engagement
- Adjusted game end criteria for better match pacing
- Improved input field handling on WebGL

### UI/UX
- Added wishlist button to the main menu
- Fixed shop font rendering issues
- Improved login screen flow

## v0.2.0 - January 2026

### New Features
- Building destruction system with DinoFracture integration
- Vehicle combat: tanks, helicopters, boats, and planes
- Spectator mode with smooth camera controls

### Weapons
- Added crossbow, flamethrower, and futuristic weapon types
- Weapon loadout system with 4 customizable slots
- Random weapon option for each slot

### Maps
- Ancient Town: close-quarters urban combat
- Archipelago: island-hopping with naval vehicles
- Jungle: dense foliage with vertical gameplay
- Mount Rainier: snowy mountain warfare

## v0.1.0 - December 2025

### Initial Release
- Core multiplayer FPS gameplay with Photon PUN2
- 4 player classes: Assault, Recon, Support, Engineer
- Primary abilities: Turret, Explosives, Invisibility, Weapon Boost
- Secondary abilities: Dash, Jetpack, Health Boost, Trip Wire
- Team Death Match, Free For All, and Capture the Flag modes
